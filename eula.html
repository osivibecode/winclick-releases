4. What the Software Does

WinClick adds items to Finder's right-click menu and interprets keyboard shortcuts while Finder is frontmost, so that Windows habits — Cut and Paste of files, Delete, F2 to rename, Enter to open — work on macOS. To do so it requires Accessibility permission for its background helper and a Finder extension enabled in System Settings.

File operations are irreversible in the usual ways. "Delete without the Trash" permanently removes files, and macOS asks you to confirm each time. Moving and creating files behaves as it does in Finder. You are responsible for your own backups; see the disclaimer below.

5. Changes to Your System

The Software does not modify macOS itself, with one exception you control explicitly: the "Use F1, F2… as standard function keys" switch changes a system-wide macOS preference, and turning it off restores the default. "Always Open With" changes which app opens a file type — the same setting Finder's Get Info offers — and it persists until you change it again.
